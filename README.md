# 🚁 Quadcopter Motion Control System

This project simulates a quadcopter motion control system using PID-based control logic and mathematical modeling. The system includes a real-time control loop, physics simulation, and visualization components.

---

## 📌 Project Overview

The objective of this project was to design and simulate a quadcopter stabilization system.  
The controller calculates required motor outputs based on positional and orientation errors using PID control.

Key concepts:
- PID Control
- Feedback loop systems
- Real-time simulation
- Mathematical modeling of motion dynamics

---

## 🗂️ Project Structure

- `main.py` – Entry point
- `controller.py` – Control system logic
- `pid_controller.py` – PID implementation
- `simulator.py` – Motion simulation
- `visualization.py` – Graphical output
- `math_utils.py` – Mathematical calculations
- `Quadcopter.py` – Drone model
